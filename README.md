# 电台播出与版权窗口排程

一个不依赖第三方包、使用 SQLite 和标准库 HTTP 服务的电台排程项目。系统把“计划排期”和“实际播出”分开保存，支持地区授权、日期窗口、禁播时段、节目冷却、赞助商间隔、直播临时替换、实播对账与版权越界检查。

广告合同、节目排期和播出回执共用一份**名额账**：每份合同按地区、日期和节目版本购买次数；排期占用名额，改版/撤档重算未播部分，播出回执凭回执号只核销一次，写入失败后可凭合同号恢复。

## 运行

需要 Python 3.11+。

```bash
python app.py
```

默认端口为 `8111`，页面地址是 <http://127.0.0.1:8111>。第一次启动会创建 `radio.db` 并写入三条演示排期。也可以设置端口和数据库位置：

```bash
PORT=9000 RADIO_DB=/tmp/radio.db python app.py
```

## 测试

```bash
python -m unittest discover -s tests -v
```

测试覆盖完整流程：排期、临时替换、播放日志、按日期对账；同时覆盖时间重叠、未授权地区和实播错节目等失败场景。名额账部分覆盖：合同授予、排期占用、超投提示剩余名额与冲突节目、改版重算、撤档释放、回执幂等核销、凭合同号恢复、各地联播各算各的、两名排期员并发先到先得，以及占用/剩余时段。

## 名额账规则

- **合同**（`contracts`）：广告主按 地区 / 日期 / 节目版本 购买次数，唯一。创建合同即授予等额名额（`grant`）。
- **排期占用**（`occupy`）：排期时按节目版本匹配合同并扣次；剩余名额不足时拒绝排期，错误里带**剩余名额**和**冲突节目**。各地联播各扣各地区的合同。
- **改版重算**：`replace` 换节目版本后，释放旧版本占用、改占新版本；已播出的排期不动已核销的账。
- **撤档释放**：`cancel` 撤档后释放该排期的占用。
- **回执核销**（`writeoff`）：播出回执先释放占用再核销；同一回执号（`receipt_no`）只核销一次，重复提交不重复扣。
- **凭合同号恢复**：`recover` 清空该合同除授予外的全部流水，按当前排期与播出回执重建，用于写入失败后对账。
- **并发**：所有写事务用 `BEGIN IMMEDIATE` 串行化并设置 `busy_timeout`，两名排期员同时提交时先到先得，后到者读到的是前者提交后的剩余名额。

## 主要 API

- `GET /api/state`：节目、排期、合同名额和最近对账异常
- `POST /api/programs`：创建节目并授权地区
- `POST /api/programs/{id}/regions`：追加地区授权
- `POST /api/contracts`：创建广告合同并授予名额
- `GET /api/contracts?date=&region=&advertiser=`：合同及占用/核销/剩余
- `POST /api/contracts/{id}/recover`：凭合同号重建名额账
- `GET /api/availability?date=&region=`：已占用排期与剩余时段
- `POST /api/schedule`：创建排期（占用名额）
- `POST /api/slots/{id}/replace`：改版换版本并重算未播名额
- `POST /api/slots/{id}/cancel`：撤档并释放名额
- `POST /api/playout`：登记实播回执（带 `receipt_no` 幂等核销）
- `POST /api/reconcile`：按日期生成漏播、错播、时长偏差和超授权异常

准备排期时填写 `air_date`、`start_time`、`program_id`、`region`。页面会直接显示校验错误，不会保存失败的排期。
